# 土佐弁の基本

高知の人は**土佐弁**を話します。よく聞く言葉：

| 土佐弁 | 標準語 | 意味 |
|---|---|---|
| 〜ぜよ | 〜だよ | 強調 |
| 〜き／〜きに | 〜から | 理由 |
| まっこと／げに | 本当に | 本当に |
| 何しゆう？ | 何してる？ | 何をしているの？ |
| たっすい | 物足りない | 物足りない、弱い |
| おきゃく | 宴会 | 宴会 |

例：「今日はまっこと暑いき、水飲みや」＝今日は本当に暑いから、水を飲んでね。
わからないときは「もう一度、ゆっくりお願いします」と言いましょう。
